## Instruções

1. Acesse cada problema pelo link fornecido.
2. Resolva o problema na linguagem de sua escolha.
3. Após a submissão ser aceita (**Accepted**), guarde o link da submissão.
4. Nomeie o arquivo-fonte seguindo o padrão: `<id_problema>.c` ou `<id_problema>.cpp` (ex: `863B.cpp`).
5. Para cada questão resolvida, preencha diretamente no formulário a análise de complexidade no campo de resposta.

> **Atenção:** É proibido utilizar funções prontas de ordenação (ex: `sort()`, `qsort()`). Caso sua solução exija ordenação, o algoritmo deve ser implementado manualmente.

## Análise de Complexidade

Para cada questão resolvida, copie e cole no campo correspondente do formulário:

```
Questão [N] — [Nome do Problema]
  Big O: O(?)
  Por quê: (explique em 1 ou 2 linhas o motivo)
```

**Exemplo — Football Kit (432B)**

```
Questão — Football Kit (432B)
  Big O: O(n + m)
  Por quê: Percorre os n times uma vez para contar frequências,
           depois responde cada uma das m consultas em tempo constante.
```

> Análises sem justificativa não serão consideradas.
